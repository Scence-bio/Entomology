# Atlas of Entomology — ئەتڵەسی مێرووناسی

سەرچاوەیەکی فێرکاریی کراوە بۆ مێرووناسی، بە **کوردی**، **عەرەبی** و **ئینگلیزی**.  
ماڵپەڕ: [www.entomo.online](https://www.entomo.online) · وەشان **0.2.0**

An open teaching atlas of entomology in Kurdish, Arabic, and English.  
أطلس تعليمي مفتوح لعلم الحشرات بالكردية والعربية والإنجليزية.

## ئامانج / Aim

- ڕوونکردنەوەی پێناسە، جومگەپێیەکان، ئۆردەرە سەرەکییەکان، کێڵگە، گۆڕانەپەڕە و کلیلی ناسینەوە
- کویزی فرەزمان لەگەڵ شەهادەی فێرکاری
- پەیوەندی بە زانکۆی ڕاپەڕین و بەشی بایۆلۆجی

## تیم / Team

خوێندکارانی بایۆلۆجی، زانکۆی ڕاپەڕین (University of Raparin).

## کارکردن لەسەر کۆمپیوتەر

```bash
npm install
npm start
```

ناوخۆیی: `http://localhost:3017`

```bash
npm run build    # بەرهەمهێنان
npm test         # تاقیکردنەوەی خێرا
npm run lint     # پشکنینی کۆد
npm run deploy   # بڵاوکردنەوە بۆ GitHub Pages
```

وردەکاریی دیپلۆی و Google Sheets: بڕوانە `DEPLOY_README.md`.
